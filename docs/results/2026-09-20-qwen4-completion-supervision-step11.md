## 仍需注意

- Step7 总体学生熵约 0.063，但前 512 token 约 0.198、4K 后尾部约 0.023。长输出会显著改变 token 加权平均值；随后总体熵回升，不能仅凭一次下降诊断全局熵塌缩。

- 周期检测仅查末尾最多 2048 token、周期 1-128、匹配率至少 99%，至少 256 token。反复尝试近似推导不一定满足该条件，4 条不是所有重复的总数。
- 短 batch 约 40 秒，含长输出的 batch 约 4 分钟；生成阶段部分 GPU 等待一个长序列，并不等于训练进程失效。
- 每步问题不同，没有固定问题/初始模型反事实对照，无法把这些波动单独归因于 Block3。这里不报告 benchmark 成绩或涨点。
