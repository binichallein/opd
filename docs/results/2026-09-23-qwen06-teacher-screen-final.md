## 测试口径

- 复用64道DAPO诊断题，独立答题每题2次，共128条；前32题各取学生sample0的固定前缀，师生分别续写2次，共64条。
- 主比较中，教师接收学生实际prompt token IDs和原始前缀，不重新套教师模板，不重新编码前缀。
- Base学生为completion；官方指令学生为原生chat并显式关闭thinking。教师原生模板独立答题另作对照。
- 总响应预算16384 token，续写扣除已有前缀。采样temperature=1、top_p=0.9、top_k=-1，沿用冻结的按题目/样本/阶段派生seed。
- 使用历史grader SHA `04f7a0328be18409b55836f7a794dd31fbc982d5870bc542a8fe7c91f9490d7f`；最终再次校验token、请求、停止原因、文件哈希与历史重评分一致性。
- 以下是诊断输出正确率，**不是**完整benchmark的Avg@8或Pass@8。独立答题和续写题目范围不同，不能把两列之差直接当成前缀导致的能力下降。

## 未通过的具体原因

| 配对 | 触发的门槛 |
|---|---|
| 4B-B → 0.6B-B | 续写增益为-1.56个百分点；续写截断7/64=10.94%，超过10%绝对上限 |
| 4B-G → 0.6B-B | 续写截断11/64=17.19%，超过10%绝对上限 |
| 4B-G → 0.6B-I | 续写截断4/64=6.25%，比学生高6.25个百分点，超过5个百分点差值上限 |
| 8B-B → 0.6B-B | 续写截断10/64=15.63%，超过10%绝对上限；该值与学生相同，不能称作教师增加截断 |
| 8B-I → 0.6B-B | 独立/续写均触发截断、周期重复、缺有效boxed的绝对和相对门槛 |
| 8B-B → 0.6B-I | 独立/续写截断均为7.81%，相对学生超过5个百分点；缺有效boxed分别20.31%/7.81%，也超过相对上限 |

少数样本即可改变边界配对的通过状态，例如4B-G到指令学生仅因4条续写截断未通过。
必须保留预设阈值，同时报告连续指标及样本数，不能把这种边界结果解释成普适无效。
4B-B续写增益的95%区间跨0，也不足以证明教师显著弱于学生。
