Blockwise Policy-Drift Gating for OPD：论文解读

这篇论文和我们的 block OPD 很接近：都用 block 粒度和 mean-normalized weighting。但它的 block 信号来自 old-current student drift，不来自 teacher-vs-old block advantage。

arXiv:2606.24084 Liwen Zheng, Haiyun Jiang 提交：2026-06-23 任务：数学推理 OPD

一句话概括

论文提出的不是新的 teacher target，也不是新的 reverse-KL 形式，而是一个 detached loss weighting rule：在 rollout reuse 时，计算 behavior student 和 current student 对同一 sampled token path 的 logprob drift，把 drift 按 block 或 span 聚合，再变成 gate 去重加权原本的 OPD token loss。

主要结果：固定 64-token block gate 把 sampled-token OPD 的四项数学 benchmark 平均 pass@8 从 49.8 提到 51.6；加到 Teacher-TopK/LSM 上后平均 pass@8 达到 53.3。

方法：Policy-Drift Gate 怎么算

给定 student rollout 中的 sampled response token y_{i,t}，它先计算 current student 和 behavior/old student 对同一个 token 的 logprob 差：

di,t = log πθ(yi,t | xi, yi,<t) − log πold(yi,t | xi, yi,<t)

这里的 d 不是完整 KL，只是 sampled path 上的 old-current student logprob shift。论文强调：这个 gate 不使用 teacher；teacher top-K、teacher target 和 rollout policy 都不变。

g = exp(−τ |s|),   τ = 1

其中 s 是聚合后的 drift score。gate 会在 valid response tokens 上做 mean normalization，目的是保持平均 loss scale，同时改变不同位置的相对权重。

Lgate = Σ mi,t · stopgrad(g̃i,t) · ℓbasei,t / (Σ mi,t + ε)

两种粒度

Gate做法
Block64-Gate 把 response 切成固定 64-token blocks；block 内平均 d_{i,t}，再把 gate broadcast 到 block 内所有 token。
NewlineSpan-Gate 按换行符切 span；太短的 span 合并，太长的 span 再切；没有 delimiter 时 fallback 到固定 chunk。

为什么要 block

论文的直觉是：token-level old-current drift 太噪，sequence-level 平均又太粗。64-token block 是中间尺度：能平滑单 token spike，又能保留长推理链中局部 stale 区域的信息。

这个问题设定和我们的 block OPD 很像，但它解决的是 rollout reuse 下的 stale / drift weighting；我们解决的是 teacher-derived advantage 的 temporal aggregation。

论文结论

Block64 对 sampled-token OPD 和 LSM 都有正向 aggregate gain。作者认为 local old-current policy drift 是 rollout reuse 时有用的控制信号，block-level gate 是一个简单实用的 robustness default。

NewlineSpan 也能提升 aggregate，但不如 Block64 稳定。论文猜测它对模型格式行为和 underlying loss 更敏感。

我对这篇的评价

这篇对我们威胁很大，因为它已经把“block + mean-normalized weighting + OPD”这几个关键词占住了。但它的创新点和我们的方向仍然不同。

它是 student drift gate；我们是 teacher-derived block advantage aggregation。

和我们方法的关键区别

维度Blockwise Policy-Drift Gating我们的 mean block OPD
block 信号old-current student drift：log πθ − log πoldteacher-vs-old advantage：log πT − log πold
teacher 参与gate 不用 teacher；teacher target 不变teacher 直接决定 block advantage
监督单位仍是 token-level base loss，只是乘 block gate把连续 token 变成 block-level supervision unit
研究问题rollout reuse 时哪些位置 stale，需要降权连续 token 是否应该共享 teacher-derived reverse-KL signal
与 LSM 的关系可直接加到 LSM 外面目前还没和 LSM 组合；这是我们下一步重要 baseline
写论文时不要说“我们首次提出 blockwise OPD”。更稳的 novelty 是：我们研究 temporal aggregation of teacher-derived reverse-KL advantages，而不是 student-only policy-drift gate。

启发对我们该做什么
他们用 200-step fixed budget我们的 50-step 结果只能算 early evidence，需要补 200-step 对齐实验。

他们只 gate，不改 teacher target我们可以做组合实验：mean block OPD × policy-drift gate，验证二者是否正交。
他们提出要 sweep block sizes我们也应 sweep block size 2/3/4/8 或更长 block，并加 grad norm tail diagnostics。
